# Harold Ave. — first map implementation

2026-09-10. Visual candidate for user review, not final visual acceptance.

Implemented: separate Harold street catalog; reusable brick/window/store/stoop/cutaway renderer derived from first street asset style; 12 curbside parked vehicles facing west on north curb and east on south curb; clear center road with actual arriving campaign vehicle; alley mouth, dumpsters, service props; nighttime lights and lit windows; green street sign; fixed left defender/right attacker deployment for first map review; local street gang defending and Russian mafia attacking.

world/harold_location.gd is the shared campaign/tactical name source. RoadSegment.street_name serializes with old-save fallback. Starter campaign neighborhood and objective use the shared identity. This still runs in the existing debug HQ-assault mission shell; broader campaign-location-to-layout selection is future work.

Art and physical props share footprints. Stoop masonry sides supply cover; stair tread artwork is traversable ground without an elevation simulation. South-side buildings use an opaque low cutaway for the existing camera. The dark continuation beyond the alley mouth is outside this map's traversable area, represented by an explicit boundary obstacle. No rain or indoor combat added.

Validation: harold_review.gd exercised launch, travel, deployment, faction identities, defender-zone bounds, persistent road-name serialization, all 76 cover destinations reachable with arriving vehicle placed, and live combat. Final active mean 58.34 FPS, 18.06ms p95; fight resolved at 13.32 simulation seconds. These do not establish visual acceptance or certify broader combat AI. Existing generic/baseline suite failures remain outside this pass.

Upcoming: selectable close/medium/far convoy arrival circles, faded placement preview, defender information advantage, ready-state opening orders, selection rectangle, arrival/reaction/arming and victory animations. The accepted full specification is HAROLD_AVE_PRODUCTION_BRIEF.md. ARRIVAL_OPTIONS currently records authored candidate centers/radii only; the new choice UI and circle enforcement are not implemented. Current play uses the medium/right rectangular pocket supported by the existing controller.

Reproduce: Godot --path . --script tools/dusk_review/harold_review.gd. Outputs go to tools/dusk_review/harold_results. Art is generated by retained draw nodes from code and the existing street textures; no external image-generation dependency. Reuse the construction vocabulary with another catalog for the next block.

## Frontage and street context revision

- Streetlight poles are taller while retaining their ground anchors.
- Stoop walls render as short depth-sorted masonry sections; reviewed the crouched defender at the west stoop in the close battle capture. Stone treads and landing use a cooler concrete palette.
- Harold Apartments uses modest raised serif letters directly against brick, with no signboard. Mercer Mini-Mart uses bold conventional lettering on a worn cream banner.
- Removed the custom pixel glyph renderer. SystemFont currently selects Georgia, Arial and Old English Text MT on the Windows development machine; a portable exported asset/font solution is still needed before cross-platform release.
- Garbage bags have rounded uneven bodies, tied tops and creases; loose debris collects around rubbish/delivery locations and the alley rather than uniformly tracing the curbs.
- Red blackletter Mercer Saints M has no backing. Based on the recovered approved-emblem description; the exact image from Idea Repository was not accessible, so the mark is provisional pending comparison.
- HUD still needs an agreed design: current overlapping text and weapon tiles are inadequate. Discuss compact roster and selected-unit orders before implementing its replacement.
