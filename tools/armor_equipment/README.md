# Armor equipment

Three independent, single-slot torso armors: Patrol Vest (+15% HP), Field Carrier (+30%), Reinforced Carrier (+50%). Fictional model names, not real ballistic certifications. Every class and training tier can use any armor.

Battle capacity = 1.5 × (1 + armor bonus): 1.725 / 1.95 / 2.25. The existing absolute wound threshold, damage, training bonuses and weapon behavior remain unchanged. Armor adds HP capacity, not damage reduction, a second regenerating shield, or stacking bonuses. New participants receive their configured capacity once at battle creation. Armor is strictly an HP modifier: equipping it never changes any unit outfit, sprite, portrait, or animation. The vest illustrations appear only in equipment purchasing and selection screens.

Campaign inventory counts unequipped vests; equipping consumes one, swaps return the old vest, unequipping returns it. Deployed units cannot change armor. Unit armor and faction inventory serialize through the existing save system; older saves have none. No invented durability/repair system. Initial purchase prices $300 / $750 / $1500 are provisional balancing values. Use ARMOR STORE on the campaign screen. The sandbox has all armor unlocked, with an independent selector for each of its ten units and an ARMOR catalogue button.

HUD: training stars above 0–3 midnight-blue circles (#162b50) with silver borders (#b9c0cb). The HP bar uses the equipped maximum. Product artwork contains only the three vests, no wearer, generated from original editable SVG sources with the arsenal's native illustration workflow. Patrol Vest uses light tan fabric, Field Carrier retains its slate color, and Reinforced Carrier uses black fabric with restrained charcoal highlights.

G36C carry rail lowered from 6 to 3 drawing units with identifiable loop retained. M4A1 has a slimmer AR-style receiver, exposed buffer tube, compact telescoping stock, narrow handguard and separate barrel. Existing attachment anchors, total weapon length and outfit geometry retained. Rebuild targets only these two models (42 faction sets + 6 legacy variants). Existing legacy foot-border contacts must not increase.

Validation: 8,280 armor combinations; 96 real store/sandbox/HUD/battle checks; 2,070 existing roster rule combinations; raw PNG export verified for all three armors. Rebuilt 48 rifle sets / 88,320 frames, with 1,680 approved-body geometry checks and zero faction atlas border contacts. Reviewed standing shoulders, front/side/aimed proportions, HUD placement and purchase artwork.
