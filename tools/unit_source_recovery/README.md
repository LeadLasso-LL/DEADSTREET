# Dead Street — action review

Open action_review.html to inspect all three outfits with all three weapons in eight directions. Select cover, hit reaction, injured movement, fall or reload. Pause and scrub; non-looping clips hold their last frame.

street_rehearsal.mp4 places selected actions in the recovered street scenery. It is a scripted visual rehearsal, not the main game's tactical simulation.

## Rebuild

Requires Python, NumPy, Pillow, Inkscape and FFmpeg. From this folder:

```
python render.py
python package.py
python street_rehearsal.py
```

Editable source lives in src/. The approved parent running/combat sources are not modified. Atlases contain the delivered frames. Loose intermediate SVG/PNG caches are regenerated by render.py and are omitted from the compact source package.

All assets are review candidates. See BUILD_REPORT.md for results and limitations; INTEGRATION_NOTES.md for the asset contract and blocked live-game work.
